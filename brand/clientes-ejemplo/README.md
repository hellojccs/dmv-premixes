# Logos de clientes — EJEMPLO

Marcas **ficticias** creadas solo para mostrar cómo se verá la franja de clientes del hero.
No representan clientes reales. Reemplazar por los logos reales cuando el cliente los entregue
(idealmente SVG o PNG monocromo en blanco/transparente).

Los SVG usan `currentColor`: toman el color del texto donde se insertan (en el hero: White Sand).
