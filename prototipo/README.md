# Prototipo — Página de inicio

Abre `index.html` en el navegador. Es un archivo autocontenido (solo carga Archivo desde Google Fonts).

- **Editar:** `src/index.template.html`
- **Generar:** `python3 prototipo/src/build.py` (inserta el logo autorizado desde `brand/logos/`).

Textos, logos de clientes, fotos, firma y datos de contacto son **de ejemplo** hasta recibir el material final.
Rinter se carga desde `brand/fonts/Rinter-Regular.woff2` cuando esté disponible; mientras tanto se muestra Archivo.
